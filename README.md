# Brass Art · CELL — генеративная латунная люстра

Латунная люстра, узор которой рисует программа, а отливает мастер. Каждый экземпляр уникален:
у каждого своё «зерно», и из него заново рождается сетка ячеек, а у овала ещё и сама форма.
Литьё — в землю, в своей мастерской, по мастер-моделям, напечатанным на 3D-принтере.

**▶ Живое демо:** <https://a9252233314-dotcom.github.io/brassart-cell/> — выберите форму, узор,
ширину и число ламп, нажмите «Ещё вариант». Генератор работает прямо в браузере, и это тот же
код, что готовит файлы для печати в цеху.

![Шар Ø600: референс, два вида узора и крупный план узла](renders/v02_compare.png)

## Что уже есть

- **Шар Ø600, круглые ячейки** — первый к производству. Решётка из рёбер 11 мм с полукруглыми
  кромками (минимум для литья в землю), мягкие перепонки в узлах, 13.9 кг латуни.
- **Узор «капли»** — ячейки, вытянутые по меридиану.
- **Овал** — горизонтальная форма высотой 0.4 от ширины. Сама форма случайная от зерна и
  выравнивается так, чтобы центр тяжести был на оси и люстра висела ровно.
- **Размер задаётся шириной и числом ламп** (до 15): число ячеек растёт с диаметром, а генератор
  сам выбирает трубу центрального узла, класс крепления по весу и угол гиба рожков, чтобы лампы
  не касались решётки.

![Овал с узором «капли», три зерна](renders/v08_oval_drops.png)

## Как это делается в цеху

Тот же генератор режет изделие на панели под стол принтера: рез идёт только поперёк тонкого
ребра, подальше от узлов, стык встык под сварку. Шар Ø600 — 31 панель. Номер каждой панели
отливается выпуклыми цифрами изнутри и совпадает с шагом сборки, а к изделию печатается лист
сборки на стену.

## Как устроен генератор

- Центры ячеек на поверхности → диаграмма Вороного → дыры: многоугольник ячейки, отступивший на
  полребра и скруглённый почти до овала.
- Металл описан функцией расстояния и собирается в сетку
  [manifold-3d](https://github.com/elalish/manifold) (WebAssembly).
- Проверки: минимальное сечение, масса → труба M10/M12 и крепление, зазор до ламп, центр тяжести,
  размер каждой панели под стол Flying Bear Reborn 2 с учётом усадки латуни.
- `generator/core.ts` — ядро без файлов (работает и в браузере), `generator/generate.ts` — запуск
  в цеху (STL, паспорт, панели, шаблон гиба рожка 1:1), `generator/panels.ts` — нарезка.
  Все параметры — в `params.json`.

```bash
cd generator && npm i
node generate.ts ../params.json ../out   # Node 24+: STL, паспорт, панели в ../out
cd .. && node web/build.mjs              # пересобрать живую страницу index.html
```
